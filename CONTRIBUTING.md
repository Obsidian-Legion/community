# Contributing to Obsidian Legion

Start with a discussion when you want feedback, have a question, or are looking for collaborators. Open a build proposal when you can explain a concrete problem and a useful first step.

## Build proposals

Include the problem, who the project helps, your proposed first milestone, and where collaboration would help. Describe any constraints and relevant prior work. Keep the first milestone small enough to demonstrate.

## Pull requests

Explain the problem and the resulting behavior. Link the relevant issue, include validation appropriate to the change, and keep changes focused. Discuss substantial changes before investing heavily in an approach.

## Participation and membership

Public discussions are open to GitHub users. Organization membership and repository write access are granted separately by the owner. Joining a conversation does not grant administrative permissions or create a maintenance obligation.

## Respect the work

Credit other builders, follow the licenses of dependencies and assets, and do not publish private credentials or information. Test software only where you have authorization.
